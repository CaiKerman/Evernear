- `npm test`：135 项通过、0 失败，包含 16 种槽位协议组合；全部本地模拟。
- `node scripts/smoke-quick-input.mjs`：8 组通过，页面错误 0；含隔离转写、全局暂停、手动播音实际回执、PCM 复用和主历史隔离。

## 实机验收步骤

1. 从对应源码提交的 Actions 产物解压，保留/复制原 personal/；核对 exe/asar SHA-256 与扫描记录。不要关闭 Defender 或添加排除项。
2. Win10/11 分别验证任务栏位置/自动隐藏、中文选词回车、720p/1080p/4K 与缩放、全屏遮挡、设置焦点；普通小窗不能当原生任务栏控件。
3. 至少实际使用一组基础/高级/文字配置，覆盖 A01—A18、设备切换、最小化与错误反馈；记录版本、模型/音色、样本数及失败案例，排除密钥。
4. 记录 30 分钟混合交流和 2 小时值守交替：停说至首声、准备/接管、打断、结果等待；报告中位数/P95、误介入/漏句和服务商实际用量，未知部分保持未知。
5. 实测通过再更新 V5/V6、M0/M4 状态并发布正式包。现有 PR 不自动满足这些门槛。
